# Goal

Build reliable persistent module groups with simple responsibilities and durable handoffs. Each Lead-owned group has a committed `groups/<id>/group.md` definition, one fixed worktree and Coordinator, Executor and Validator roles. Registration performs finite real-session onboarding: Executor and Validator explicitly acknowledge the definition and their role responsibilities; Coordinator acknowledges only after both, and Lead receives that receipt. Onboarding sessions stop without starting business work. New definitions take effect at a safe task boundary, reset all three role sessions and require fresh acknowledgements.

One task is active per group. Coordinator scopes delivery within Lead's objective; Executor plans and implements; Validator performs exactly one adversarial plan review before implementation, then reviews each code delivery. After code passes, Validator aligns explicitly assigned module Markdown and Coordinator independently checks the alignment and checklist. Lead retains acceptance and integration authority. Different groups may work concurrently.

A lost notification, repeated submission or process restart must not lose work or approve the wrong code version. Runtime receipts and SQLite handoffs are authoritative; display text is not. Process documents are organized by group and task and preserved in Git. The group worktree stays fixed and synchronizes from Lead's committed baseline only at an idle, clean boundary. Coordinator manages declared project services through structured tools, and Lead finalization runs the target project's explicitly configured integration command.

Do not restore formal debate, Blackboard lifecycle gates, a second plan review, or autonomous Lead wakeup infrastructure in this version. Keep protocol implementation, isolated-copy evidence, original-project provisioning and cutover claims distinct. Current bounded deterministic and real-provider results are recorded in project_state.md; they do not prove original-project deployment or long-term unattended operation.
